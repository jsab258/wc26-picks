# Assembly lines (authored breadth manufactured)

Every content type moves through the same five stations. The planning unit is verified pieces per week, tracked in the throughput ledger (production/throughput.md).

Stations: 1 SPEC (what, canon constraints, acceptance checks) -> 2 AUTHOR (one agent, one deliverable) -> 3 VERIFY (instruments plus judge per D7; license gate; canon gate) -> 4 INTEGRATE (data-driven placement, engine import via generators, never hand edits to binary scenes) -> 5 RECORD (throughput ledger, roadmap row touch, history on landing).

| Line | Piece | Notes |
|---|---|---|
| Code feature | PR guarded by tests | Existing practice, unchanged |
| Prop/asset | Cleaned, LOD'd, licensed mesh in the library | Blender headless batch; license tag mandatory |
| Interior | Tier 1 authored or Tier 2 grammar entry | Seed plus delta persistence contract |
| Character | Bio, schedule, relationships, voice, face rig | Casting spec ties into gossip graph |
| Dialogue bank | Memory-conditioned lines per archetype/person | Repetition check across the bank is part of VERIFY |
| Mission | Data definition run by the generic runtime | Headless sim playthrough is part of VERIFY |
| Radio segment | Song, DJ link, advert | Brand bible references required |
| Signage/brand | Brand bible entry plus placed instances | Era and register checks |

Batching law: content generation runs in deliberate batches with a single spec per batch, never ad hoc mid-session. One brief, one deliverable (waste lesson 3).
