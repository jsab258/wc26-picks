WHAT IS BEING DONE INSTEAD OF A FIFTH GUESS. tools/runner/telegram-bot.py
--send-outbox is an existing entry point that performs exactly one outbox pass
and returns, printing what it did; it is the same pass the bot's own loop
makes. A step now runs it on his machine and commits its output. It answers by
DOING the thing rather than reasoning about it: either the sweep works, in
which case the waiting message is delivered and the fault is in the loop that
calls it, or it fails and prints the reason that has been going to a console
nobody reads all day. It is allowed to send; receipts make a double send
impossible.
