# Atlas 01 source package

Start with [DELIVERY.md](DELIVERY.md). This is an authored visual proposal, not a live scene or export pack.

Regenerate drawings with the existing Python environment:

```text
python production/art/atlas-01/scripts/draw.py
python production/art/atlas-01/scripts/reference-boards.py
python production/art/atlas-01/scripts/pub-gameplay.py
python production/art/atlas-01/scripts/asset-view.py
python production/art/atlas-01/scripts/check.py
```

Optional PNG rendering uses `node production/art/atlas-01/scripts/render-svg.cjs` with an existing Sharp installation. `CODEX_NODE_MODULES` may point to a pre-existing bundled node_modules directory. SVG sources remain viewable without Node. No script downloads assets, chooses random layouts or dispatches work.

AI concepts are retained raster outputs with their prompts and hashes. They are not deterministically regenerated by the SVG script. References are research-only and have separate rights. The Blender recipe requires a separately scheduled lane and Blender 4.2 or later because it names `BLENDER_EEVEE_NEXT`; it has only been syntax checked here. See the pending render request and interface notes before execution.
