# frameMedianMs: MEDIAN of 24 engine frame deltas after 8 discarded warm-up

#   times a whole engine frame. frameStat on each line names which one it is.
# shotMeanLuma: mean over EVERY pixel of the committed file, 0 to 1,
#   luma=(0.299R+0.587G+0.114B)/255, the same weights the Unity sim uses.
# shotNonBlackPct: percent of shotPixels with any channel above zero.
# shotDistinctBuckets: distinct 5-bit-per-channel colour buckets, of 32768.
# a shot status of WROTE needs a decoded file with more than one bucket and
#   at least one non-black pixel. BLANK, UNDECODABLE and NO-FILE are the three
#   ways it fails, and the step exits non-zero for all three with the evidence
#   still committed.
# QUEUE 059, THE TWO MEASUREMENTS RUN 17 DID NOT HAVE. Its lantern count read
#   four of four and answered `were four lights created`, while both night
#   frames were black; its mean luma read 0.5030 over a day frame whose ground
#   plane was entirely clipped. Neither number could see it. These can:
# shotClipHiAny/shotClipHiAll/shotClipLoAll: COUNTS of pixels at the top and
#   bottom of the 8-bit range over shotPixels, never a mean. shotLumaBands is
#   eight equal luma bands, band 0 darkest: a printed series, not a bound.
# band.skyTop / band.skyCentre / band.ground: THREE GEOMETRIC BANDS of THIS
#   frame, named for what they COVER and not for what is in them. skyTop is
#   the top eighth full width and carries roofline as well as sky; skyCentre
#   is the middle fifth of it; ground is the bottom fifth. Each ships its own
#   pixel count as its denominator and its own rectangle in pixels, and a
#   rectangle covering no pixel reads NOTHING-MEASURED rather than dark.
#   meanRGB is printed because a sky and a fog inscattering colour are told
#   apart by CHANNEL ORDER: before the sky landed, the day far field read
#   249.5/250.0/250.5 and the night one 188.4/179.6/179.3, which are the day
#   and night fog colours and not a sky. A printed series, not a bound.
# bandGroundOverSky: one ratio of two measured means. A ground LIT by a sky
#   and a ground MIRRORING one both raise it; the ground band's own spread is
#   what separates them, because a mirror adds variation and a lamp does not.
# skyModel / ambientModel: READ BACK off the components after the write. Both
#   were hardcoded literals in a format string until 2026-09-09 and one of
#   them was false. skyWrites=N/of=M is write-on-change: M is how many times
#   ApplyCondition ran and N how many times the sky was rewritten, and N<M is
#   the point rather than a fault. skyHdriBoundAs says NOTHING on purpose:
#   this run looks for the HDRI the shared file names and binds none of it.
# shotSunIntensityAsked / shotSkyIntensityAsked: A1(c), 2026-09-09. THE
#   VALUE THE CONDITION ROW ASKED FOR, beside the one the component read
#   back, with shotCellAgrees per frame and cellAgree=N/of=M once per run.
#   Run 38 printed five rungs that all read sky 1.000 and one control row at
#   0.350 and never printed the cross, so the cell that mattered had never
#   been rendered and nothing said so. The repeat shot is excluded from the
#   run tally, because it re-photographs shot 0 and would make the
#   denominator larger than the shot list.
# lightAim*: A6, 2026-09-09. EVERY DIRECTIONAL LIGHT'S ASKED ROTATION BESIDE
#   THE ONE ITS COMPONENT READS BACK, with the signed residual per axis to
#   four decimals. The spec has asked for a sun at pitch -36.0 since it was
#   written and this rig rendered -82.0 on every run: the arithmetic was
#   tested, the format string was tested, and nothing tested that the number
#   reached the light. lightAimStatus=AGREES is the only passing word and the
#   step refuses on anything else WITH THIS FILE STILL COMMITTED. The bound
#   is 1.0 degree and it is NOT a measured tolerance: it separates the 46.0
#   fault from a float round trip of order 1e-4. A residual printed between
#   0.001 and 1.0 is what a real bound would then be read off.
# light lines: one per probed light, the SAME camera, condition and frame
#   counts as its shot with that one light switched off. deltaMeanFull is the

# PHASE C, MATERIALS. One surface line per surface the shared file asked for,
#   with what each map LOADED AS rather than what its filename claims, and the
#   candidates tried for every map that is not there. The base material is a
#   BUILD PRODUCT made by tools/ue/make_base_material.py in the cook step: no
#   human opens the editor, which is D1 measurement (a) in one line.
#   materialBase reads MISSING when the cook did not carry the asset, and
#   every surface below is then untextured however many maps decoded.
# PHASE C, THE READBACK. Each surface line carries what the material
#   instance answered when asked for the texture and the two tiling
#   scalars straight back, and the materials line carries the run's
#   totals over the surfaces a parameter was actually set on. It is the
