# 249. RESEARCH: is there an allowlisted vision model that can read a sheet for D18?

STATUS: READY, 2026-09-10. Filed under the close-out ruling of 2026-09-10,
section 10. A blank next rung is a research task, not a finished aspect, and
the rung above the manual image pass is blank.

## The question, in one line

Is there a vision model on `ledger-v2/research/license-allowlist.md` that can
look at a rendered sheet and answer the D18 classes: is there a person under
eighteen in this picture, is there alcohol, is there gambling, is there slur
text.

## The order of work, and it is not negotiable

THE ALLOWLIST IS LAW. Nothing ships that is not on it, and a new tool enters
only through a decision record naming its weights licence. So the first
question is which models are ON the list, not which models are good. A model
that would solve this and is not allowlisted is not a candidate; it is a
proposal for a decision record, and the record names the licence before
anything is fetched.

## Done looks like

One of two outcomes, both acceptable, neither hedged:

1. A model is named, with its weights licence and its allowlist line, in a
   decision record. Then a second item builds the check, and that check is a
   guard so it ships with both outcomes watched: a real sheet it PASSES, and a
   planted sheet it must refuse.
2. No allowlisted model can do it. Then record that the rung is MANUAL until
   one exists, so that the next reader does not rediscover the question, and
   queue 248 stays the only instrument.

## What must not happen

Do not fetch weights to try one out. Do not add a host to the allowlist as a
side effect of research. Egress is heavily restricted here and most external
hosts are blocked, so this is likely to be a reading and reasoning task rather
than an experimental one, and it should say so plainly if that is what it
turns out to be.

## Dependencies and risk

Depends on nothing. Risk if ignored: the manual pass of queue 248 stays the
only check on what a picture actually shows, and a manual check that nobody
schedules is a check that happens once.
