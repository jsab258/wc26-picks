## THE CREDENTIAL RULE, and it binds every agent that touches this item

`tools/runner/config.local` is on the PC and is gitignored. It is READ by the
bot at runtime and by nothing else. No agent prints it, echoes it, cats it,
greps it in a way that would surface a value, commits it, or includes it in an
error message, a verdict line or a report. A tool that fails to read it says
`config.local unreadable` and NEVER quotes what it found. If a value ever
reaches a log or a commit, the token is burned and has to be regenerated by
Jafar, which is a cost the studio cannot pay for itself.

The gitignore is not the guard. A gitignore stops `git add`; it does not stop
a print, and every leak this class of file suffers is a print rather than a
commit.
