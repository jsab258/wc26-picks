## 2. Question 1: the historical exemption, attacked

What the code does, read at `tools/producer-check.py` 466 to 487 and 596 to
606. `historical_split(text, legacy_links)` returns `(None, text)` unless

annotation still faces the ban list, the link rules, the shape and the claim

The three scopes hold as claimed:

- Membership. An unlisted file gets `(None, text)` before any string is
  examined. The coordinator asked whether `historicalLinesUncounted` could
  exceed its denominator or be earned by an unlisted file: the numerator at
  1922 increments only from `res["historical_uncounted"]`, which is 0 by
  construction when `legacy_links` is false, and at most 1 per listed file
  checked, so it is bounded above by the listed files walked, which is at
  most the denominator `len(legacy_links)`. It cannot exceed and cannot be
  earned off the list.
- Position. `text.partition("\n")` takes one head. A BOM, a leading blank
  line or a CRLF ending all fail the strict way (no excusal), never the
  loose way.
- Count. One head, and the selftest's HIST_TWO fixture asserts the second
  line is counted (1256 to 1264).
