# Sleeper autopilot (FantasyPros ECR)

Sets your Sleeper lineups and waiver claims from FantasyPros Expert Consensus
Rankings, following each league's own rules (PPR/half/standard, superflex,
flex types, K/DEF, FAAB or waiver priority).

It's a Google Apps Script web app that runs in your own Google account: setup,
features and development notes are in [`apps-script/README.md`](apps-script/README.md).

The earlier Python command-line version was retired: the web app does
everything it did, and keeping both meant writing every fix twice. It's in the
git history if you ever need it.
